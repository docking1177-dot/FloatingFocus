# 真机验收清单

每次测试记录手机型号、系统版本、导航方式、APK SHA-256 和实际结果。至少在 Android 14、15、16 各一台设备完成；下面是待执行步骤，不是通过记录。

| 编号 | 操作 | 预期 |
|---|---|---|
| 1 | 全新安装，点击开始，拒绝悬浮权限 | 不创建窗口/服务；主界面保留授权入口 |
| 2 | 授权后返回 | 不自动开始；主动点击开始才创建一份胶囊 |
| 3 | 分别选择 5/10/15/30 与自定义；输入空、0、181 | 预设正确；无效输入不能确认；允许 1—180 |
| 4 | 连续快速点击开始，再返回主界面 | 只有一个会话和一个窗口，不重新开始或叠加 |
| 5 | 打开 B 站/浏览器等普通 App | 胶囊保持显示；外部区域滑动、点击正常 |
| 6 | 点击胶囊、点击收起、结束按钮 | 正确展开/收起；结束后窗口和通知消失 |
| 7 | 小幅手抖点击、大幅拖动、系统取消触摸 | touchSlop 内为点击；拖动不误展开；取消不触发点击 |
| 8 | 四边拖动，右边展开，横竖屏切换；重复三键/手势导航 | 窗口始终可见，避开状态栏、导航栏和刘海 |
| 9 | 自定义 1 分钟，与另一计时器同时开始 | 起始 01:00；30 秒开始灰→橙；48 秒开始橙→红和轻缓呼吸；60 秒显示时间到了 |
| 10 | 到期后等待至少 10 秒 | 只震动一次，显示知道了；没有持续震动 |
| 11 | 到期点击知道了；随后重新开始 | 旧窗口/通知/服务结束，新会话正常 |
| 12 | 计时中返回主界面或旋转 Activity | 显示同一会话剩余值；没有重置 |
| 13 | 熄屏 20 秒再亮屏；另做跨越结束时刻的熄屏 | 剩余值包含熄屏经过的时间；醒来立即校准并在未执行过时提醒 |
| 14 | 修改系统日期/时间 | 胶囊剩余时间不受墙上时钟变化影响 |
| 15 | Android 13+ 拒绝/永久拒绝通知后开始 | 可继续悬浮计时；提示降级；设置入口可再次打开通知授权 |
| 16 | 计时中撤销悬浮权限 | 服务停止或被系统终止；返回后无仍在运行的假状态 |
| 17 | 从通知结束，或系统前台任务管理器停止 | 正常结束；下次进入能开启新会话 |
| 18 | 强制停止应用/重启设备 | 不自动恢复或创建幽灵窗口 |
| 19 | 系统动画倍率 0，检查最后阶段 | 无呼吸动画，静态颜色仍可提醒 |
| 20 | 重复开始/结束 20 次 | 无多余窗口、持续回调、明显内存增长或崩溃 |

### 0.1.1 拖动回归（待执行）

- 覆盖安装后确认版本为 0.1.1；分别从标题、展开后的「结束计时」「收起」、文字之间和边缘留白开始拖动，窗口均跟随移动。
- 归零后从「给眼睛一个休息的机会」和「知道了」区域开始拖动，窗口仍可移动。
- 拖动结束按钮、收起按钮或知道了按钮后松手，不触发结束/收起；拖出后移回起点再松手也不触发。
- 分别轻触标题、收起、结束计时、知道了，原有操作正常；轻微手抖不误判为拖动。
- 在屏幕四边展开、等待归零，再从新增区域拖动；横竖屏及导航方式变化后完整窗口仍在可见范围内。
- 拖动中第二根手指按下，再全部松开，不误触按钮；之后单指拖动和点击恢复正常。

可辅助检查：

```sh
adb shell dumpsys activity services app.floatingfocus
adb shell dumpsys window windows
adb logcat -s FloatingFocus AndroidRuntime
adb shell appops set app.floatingfocus SYSTEM_ALERT_WINDOW deny
```

最后一条会主动撤销本应用的悬浮权限；测试后通过应用授权入口重新允许。电量、温度和卡顿需实际长时间运行测量，不能由编译成功推断。
