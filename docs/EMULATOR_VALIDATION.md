# Android 16 模拟器验证

2026-10-21，已安装 Android Emulator 37.2.12 和 AOSP Android 16 / API 36 x86_64 镜像，创建 `FloatingFocus_API_36` 并以 WHPX 加速实际启动。使用本地交付的 0.1.1 Debug APK，SHA-256 未改变。

通过 ADB 安装并启动应用；在专用测试模拟器上预先授予悬浮 app-op，在界面设置自定义 1 分钟并开始，回到启动器进行跨应用浮窗操作。计时自然归零，未修改设备时间或注入完成状态。

## 实际结果

| 操作 | 观察与断言 |
|---|---|
| 从结束计时按钮起拖 | 窗口从 (644,235) 移至 (364,635)，继续显示展开面板，未结束 |
