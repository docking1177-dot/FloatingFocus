## 异常、恢复与验证边界

1. 开始时 HyperOS 拒绝ADB触控，错误为 INJECT_EVENTS permission。安装成功，但尚未启动计时。用户在手机上处理USB调试安全开关后，一度只剩文件传输接口；刷新/重启电脑ADB仍未列出设备。用户恢复调试连接后，真实点击成功，再开始正式采样。这是本次测试准备阶段的权限/连接阻塞，已恢复；不记为FF应用缺陷，也未将阻塞期间计为通过。
2. 电脑与手机壁钟约相差5秒。节点分析使用手机日志相对手机会话开始记录；不混用电脑绝对时间判断60秒计时是否准确。
3. 本轮无FF崩溃日志，14个采样均为一个可见FF浮窗、窗口token相同；截图读数和检查点累计均继续。归零展开由338×131变为492×266，是到时操作面板的预期展开。
4. 本轮只验证已配置的普通横胶囊、抖音前台短流程；没有覆盖长时省电、锁屏、旋转、拖动、边缘连击或C4。既有Redmi整窗闪动专项保持待完整复测，不因这次短测关闭历史问题。
5. 未亲手感受振动，也未收录/试听提醒声音。本次阶段判断依据实际画面和日志，不将振动请求当触感通过。录屏是画面证据。
