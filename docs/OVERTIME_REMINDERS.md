# 超时提醒

## 用户能做什么

从「设置 → 超时提醒」管理倒计时归零后的提醒。默认关闭，不改变升级前体验。开启后默认只允许背景提亮、描边脉冲和超时状态；短提示音、两段短震动须分别开启。

基准间隔默认5分钟，分秒滚轮范围1—180分钟。每轮在±20%范围内选择一次，例如5分钟为4—6分钟；当前设置页直接显示范围。刷新、展开收起和旋转不重新抽时间。

「稍后提醒」使用共用分秒滚轮，用户选择的一轮不再浮动；之后恢复自动浮动。它不加时、不清空超时、不改变累计或每日App额度，取消不增加次数。首页提供入口；「主动选择下一次」模式额外在普通超时浮窗展开区提供入口，不因每轮提醒强制展开。

## 分级和允许效果

| 条件 | 最高候选级别 | 行为 |
| --- | --- | --- |
| 第一轮 | 轻量 | 最多一种允许的视觉效果 |
| 后续、超时未满基准3倍 | 轻量 | 视觉轮换 |
| 后续、超时已满基准3倍 | 标准 | 最多两种，可加入已经开启的短音或震动 |
| 主动确认延后达到3次 | 明显 | 更清楚的视觉反馈，并在控制区显示计划、实际和次数 |

实际级别始终受用户选择的上限约束。轻量不发周期声音或震动；明显不再增大面积、提高音量或缩短间隔。最近两轮效果降低选择权重但仍可重复，效果不足不新增未允许效果。未点击不作为用户未察觉的判断依据。

短提示音为系统生成的120ms媒体提示，固定克制音量，不附带音频素材。震动为75ms、间隔90ms、75ms，沿用原兼容API和系统限制。声音、震动独立选择，静音、勿扰、媒体音量和音频焦点可能使请求不执行。日志不等于实际听感或触感。

周期强度使用本页独立上限，不读取普通渐进强度或C4固定的零动画强度。原归零提醒仍由CompletionReminder管理，不受本页总开关改写。

## 重要行为的来源

以上默认值、固定±20%、三级阈值、独立强度、主动选择入口和生命周期规则来自本轮补充设计，用户已确认整组设计。原始明确需求与补充建议仍分别保留在[设计](superpowers/specs/2026-11-04-overtime-reminders-design.md)。

计划时长采用Countdown.totalPlannedMillis，包含已确认加时；实际采用Countdown.elapsedAt/OvertimeReadout。稍后提醒不是计划，不计入计划值。延后次数只属于当前超时段。

## C4与生命周期

- C4归零前不排期，不改变下包/输入/口令/拆除/爆炸链路。归零后只为折叠态应用兼容视觉；完整装置不变，不自动展开收起。展开清除旧视觉cue，收起不补播。
- 爆炸及尾音、成功语音忙时跳过本次短提示音，不抢占、不补播；其他兼容效果仍可使用。C4音轨开关与新增周期短音开关各自控制。
- C4禁止暂停和加时，归零后可以正常结束，现有首页/通知/组件/磁贴限制保持。
- 总开关关闭取消排期和效果；重新开启从当前时刻排期。允许效果、声震和上限即时收紧，不重新抽已有截止。
- 修改基准会重排自动轮次，已主动选定的一次截止保留。加时取消当前超时段，下一次归零重新开始提醒分级，不改累计。
- 同一服务中只保留一个单调截止。回调校验会话与段，先消费再输出；延迟/唤醒最多一次，不连续补发。明确间隔表示不随机，系统休眠仍可能延迟。
- 结束、撤权、任务划除及服务销毁取消调度和资源。进程结束不恢复会话、不补停机时长，仅持久保存配置。普通超时原本不能暂停，本轮不增加该能力。

## 实现与检查入口

`OvertimeReminders.kt`为纯策略与配置；`OvertimeReminderSettingsStore.kt`独立使用overtime_reminders偏好；`FloatingService.kt`唯一调度；`OvertimeReminderFeedback.kt`管理有界声震资源；`OvertimeVisualFeedback.kt`只绘制；`OvertimeReminderScreen.kt`复用设置及首页滚轮；`FocusOverlay.kt`复用普通超时操作和固定时间锚点。

不存在第二套会话、计时、额度或历史记录。新设置不写入预设，不新增权限、依赖、监测或保活。

检查：`scripts/check.ps1 -Offline`、`-Variant Release -Offline`；JVM用`-Mode Unit`。设备专项为`test-device.ps1 -Suite overtime_reminders -Serial <专用模拟器> -AllowTestDataChanges`，真实等待1分钟基准的周期，不加速正式计时；备份并恢复测试数据。存在旧桌面固定入口时保护门禁会拒绝，不能为通过检查而清理用户入口。

当轮实际结果及真机待验见[成果与证据](validation/20261104-overtime-reminders.md)，不是存在脚本即通过。
