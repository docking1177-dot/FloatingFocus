范围以本轮用户需求为准，不改计时口径、C4 时间轴、声音或退出规则。

1. 保留原始 Git 改动；在 `codex/overlay-stability` 用 Debug 测量日志、窗口帧与连续录屏调查普通超时和完整 C4 的逐秒变化。不得把未复现写成已修复。

3. C4 专属阶段前继续走普通时间锚点；设备阶段保留独立定位。复测边缘及原时间区域连续点击。
4. 将有效 C4 会话快照发布到共享会话状态，由共同控制策略和服务拒绝暂停/继续。先验证失败测试，再实现，普通会话仍可暂停，阶段前仍可结束。
5. 运行相关 JVM、构建/Lint、设备与脚本回归，补充证据及未完成真机项；审查后独立提交并同步开发分支，不合并或发布。

初步证据：诊断 APK 在 API36 模拟器的普通超时与完整 C4 采样中暂未看到逐秒位置变化。旧探测的 C4 前阶段未等待窗口就绪，不能作为锚点验收；后续需修正探测条件。
