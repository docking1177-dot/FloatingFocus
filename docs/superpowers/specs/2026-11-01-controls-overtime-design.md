# 系统控制、首页滑动与超时显示

## 目标与边界

基于现有单一 FF 会话、FloatingService、Countdown、预设与原窗口迭代。不增加监测、运行时权限、第三方依赖、保活、平行计时；版本不变，不自动合并或发布。当前基线89d27c0，用户原AGENTS空行改动和asset素材保留。

## 已明确或已确认的行为

- 原生 Quick Settings Tile，复用启动默认配置及单一会话。
- 用户已确认：空闲开始；普通计时点击暂停、暂停点击继续；普通超时或C4点击查看FF，避免点击即结束；锁屏先解锁。
- 首页内容左右分页，与标签共用当前页；顺序来自HomeNavigationStore，页面状态按栏目ID保留，启动中禁切换/排序。
- 普通倒计时超时显示当前段超时及整个会话已计时；累计直接读取Countdown.elapsedAt，不能再加超时或各段计划时长。暂停沿用现有SessionClock口径，不推测App前台使用。
- 普通超时布局提供多个Debug候选、真实实时预览和独立本机选择，不进入预设/正式外观配置。
- C4爆炸及之后保留两种专属形态；可以收起、展开和拖动；所有入口均禁止加时。
- 用户已确认：C4从归零起允许正常结束（尾音未完也可结束并停止尾音），不再校验口令；仍不暂停。归零前维持口令规则。

## 采用的实现与UI建议

1. 系统磁贴采用24dp单色时钟图标，系统决定底色与形状；名称“FF计时”，副标题说明状态和下次点击动作。暂停显示非激活色但可继续，启动请求忙时暂不可用。长按进入现有设置；设置中按系统确认添加，旧系统给出手动编辑控制中心指引。磁贴只在系统监听期间收集现有状态，没有常驻观察或轮询。开始复用WidgetStartActivity，Android14+用PendingIntent展开Activity。锁屏延迟操作绑定点击时的会话/计时段，解锁后重验，不能控制后来新建的会话。
2. 分页采用已有Compose foundation的HorizontalPager，不自建手势识别。栏目顺序改变时按ID重建分页锚点，SaveableStateHolder位于其外；纵向滚动留给各页，内部控件先消费手势。标签排序期间禁分页，分页进行时不启动排序。
3. 普通超时三候选为“超时主显”“累计主显”“并列读数”。首个最接近现状，Release暂用其双行读数；Debug选择、其他候选及选择器隔离在debug源码集。本轮只确定比较能力，正式最终样式仍待体验后决定。C4不读取这份偏好。
4. C4增加持续OVERTIME状态，将专属主题激活与口令锁定分开。爆炸尾音照旧仅一次；归零后常态显示超时标识和+时长，完整装置LCD显示+时长及超时标识。原实体键盘的#位置显示“结束”，其余键不输入、不缓存；显示屏/实体背景仍切换形态。首页、通知、组件可结束，不提供加时或暂停。
5. 时长较长时使用时:分:秒，标题不自动缩字；沿用原窗口整体屏幕适配、可见时间锚点和实际轮廓触摸。

## 取舍与替代方案

- 直接控制磁贴比只启动App少操作；只打开FF仍保留给超时和C4等需要明确选择的状态。直接结束磁贴更快但误触会结算会话，故未采用。
- C4归零即解锁结束让用户无需等尾音；替代为尾音后解锁会额外等待约5.902秒，用户已选前者。归零前与归零后分别采用口令与明确结束动作。
- 采用原生Pager而非手写左右拖拽，以复用方向判定、分页和读屏；保留按ID保存状态，修复此前Compose重用滚动层的风险。
- 双行作为正式路径的临时默认，避免实验选择直接进入普通设置；其余候选严格Debug隔离。三个方案仅展示变化，同一累计数据、颜色、大小、透明度和操作回调。

## 结构与验证

- C4Timeline/C4Runtime/C4Frame及SessionState操作能力，服务再次按单调时钟检查，不能靠UI隐藏防绕过。
- ReminderPresentation新增只读超时读数，OvertimeReadout与Debug/Release同名OvertimeHeader共享入口。
- HomeEntryPager围绕原三页内容，HomeEntryTabs继续排序；不复制计时、预设或App启动流程。
- FocusTileService与TimerTileModel只路由现有默认启动及带会话标识的控制，SettingsHome提供添加入口。
- JVM验证C4边界、口令、所有控制能力、累计多段和长时长、磁贴状态与陈旧请求；设备验证首页点击/滑动/排序/重建、原窗口与实验布局、C4超时结束/防加时、真实SystemUI添加与点击。
- 保留独立check/results身份，导入统一测试库。模拟器不证明HyperOS控制中心排版、锁屏/后台策略或真实音频听感。
