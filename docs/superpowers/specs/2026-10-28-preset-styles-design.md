# Debug Preset Styles Design

本轮设计以用户提供的完整规格及默认方案为准，仅比较首页预设展示，不决定正式样式。

- 明确需求：三种候选、共用真实预设和操作、稳定顺序与 ID；快捷 App 维持四列；保留保存/管理/新建。
- 默认行为：Debug 首次图标方案卡，本机独立持久化，立即共享至首页；运行中可选但真实卡片仍禁用。预览只渲染，不连操作。
- Release：保持当前正式双列卡片，选择器、候选渲染、偏好存储均不打包。
- 技术选择：TimerPresetsCard 保留业务和页头，只把原网格提取到 source-set 同名 PresetItems；Debug 提供三样式实现，Release 保留原网格。替代为 main 中按布尔值隐藏实验组件，会违反真实源码集隔离；复制三套业务会造成权限/禁用语义分叉。
- 普通 UI：复用主题、本机 AppIcon、Material Surface 按下反馈；无固定文本高度、名称自然换行，Android 触摸目标至少48dp。行布局右侧对齐时长，不加箭头。
- 不改预设编码、位置、记录、C4、服务、权限、依赖、版本；用户素材不提交。main 已按新指令快进至4787cc0；本轮在codex/preset-card-styles开发，不把新工作自动合回main。

验证：同批数据三张截图；实际切换/重启、空/单/奇数/较多、同App多预设/长名/正计时/缺图标、小屏大字体、预览无副作用、实际启动/缺权限/失败/禁用。复用统一备份还原设备脚本；Debug/Release Full及Release包类检查。
