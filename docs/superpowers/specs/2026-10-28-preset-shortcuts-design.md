# 预设桌面快捷方式

## 已确认
用户确认整组推荐行为：保留所有活跃会话（含暂停、超时及 C4），不替换、不结束；缺少悬浮权限允许添加，启动时授权，返回点击「继续启动」。名称/图标跟随最新预设，改绑后打开新 App；Debug/Release 共用正式业务。只执行稳定预设 ID，不保存配置快照，不按名称回退；添加须系统支持和用户确认。

## 实现选择与替代方案
使用官方 ShortcutManager 的 pinned shortcuts；固定 ID 为 ff.preset.<预设 ID>。管理列表增加操作，沿用原绑定编辑器。独立的 PresetShortcutActivity 只作受控启动与修复入口，复用 AppTimerLauncher/FloatingService；独立 task affinity 保护原 FF 栈和草稿。直接路由 MainActivity 会把外部 Intent 消费、权限返回和主页状态混在一起，且启动器的 task flags 可能清理原栈；不采用。没有新增计时系统、服务、依赖或权限。

Store 严格区分有效空列表和读取失败；失败不写回、不禁用入口。保存/删除、回前台、成功确认时做有限同步；位置变化不重复更新图标。更新被限流不回滚预设，下次前台重试，不轮询。创建 API 在工作线程执行；仅短暂合并连点，请求返回即结束本地忙状态，无回调不判失败。私有 manifest receiver 通过 immutable PendingIntent 接收成功，只同步信息并反馈，不启动计时。

轻量启动页校验 action/有界无控制字符的 ID，忽略任意外部包名、时长、组件与配置。首次可见时只消费一次；重建不自动重试，权限/修复返回需明确继续并重新读取。成功离开不留下中转页；已有会话只提示。共享启动器增加进程内启动互斥，覆盖服务尚未发布 active 的连点窗口，失败只取消自己新建的启动。

## 普通 UI 决定
复用主题和现有按钮；管理操作换行排列以适配第四项。错误页提供取消、重试或编辑预设，权限页复用 OverlayPermission。图标复用本机 drawable 读取与统一占位，AdaptiveIcon 用系统 Icon 保存其形态。最终裁切和 FF 徽标由启动器决定，不保证不同启动器只有一份。

## 验证边界
JVM 检查身份、删除/读取失败、条件校验和消费状态；真实专用模拟器检查系统确认/取消、桌面图标与点击、冷热启动、更新删除、权限返回、冲突、记录及草稿保护。真机/其他启动器未执行则明确报告。沿用原备份策略；不发版、不合并。
