# 正计时周期提醒

设置 → 正计时提醒。初级、中级、高级是三条独立的周期规则，不是倒计时阶段。首次均关闭，初始间隔分别5、15、30分钟；每级可单独设置1秒精度的间隔（1—180分钟）和背景提亮、描边、累计状态、两段短震动、短提示音。空效果不发出提醒。

## 配置归属与声音许可

- 普通计时、快捷App和默认组件/磁贴开始读取当前规则；预设保存自己的规则，首页、桌面和组件预设复用同一启动器。会话开始后固定，编辑只影响以后启动。
- 保存当前会把规则存入正计时预设；预设编辑是独立草稿，取消不写全局、预设或会话。倒计时预设不依赖正计时规则读取。
- 声音和震动另有本功能全局总许可，首次关闭，立即生效且不写入预设。各级请求声音/震动仍须得到总许可；开启总许可不重放旧提示。系统媒体音量、静音、勿扰与音频焦点限制继续有效。标准周期强度独立于原渐进强度。
- 旧预设/恢复检查点缺少新字段时三级关闭；显式损坏的新字段报错，不猜成旧数据或改用当前全局。旧记录不重算。

## 周期与生命周期

周期依据现有Countdown的累计有效运行时间，含异常续计承接值；手动暂停和随亮屏模式的息屏暂停不累计。各级在自身间隔的整数倍触发；同一次调度多级到达只采用最高级配置，其他到达规则也推进，避免声震叠加。

同一FloatingService持有一个纯周期引擎及下一节点回调，不依赖Compose刷新。延迟最多发一次，不回放队列；暂停时已经错过的节点静默消费，继续后不补发。异常续计从累计之后的未来节点继续，停机时间不计。结束、进程清理和新会话清除回调与效果，不新增服务、权限、唤醒或后台保活。

设置中的视觉预览使用真实渲染器和假数据，不启动会话、服务或记录。颜色/效果编辑自动演示约1.6秒，采用同一真实时间进度；系统动画2倍不延长至被清理截断，关闭动画时显示关键状态后恢复。A至B平滑变化，A/B和随机色离散切换，文字按实际背景保持可读。声音/震动仅在明确选用对应效果或点击试听时请求，页面后台及退出立即释放试听资源。

## 时间显示

所有可控正计时读数复用formatElapsed：不足1小时MM:SS，达到1小时HH:MM:SS，小时至少两位且超过24/99继续增长。普通倒计时/C4剩余格式、历史原秒值及超时累计口径不变。

浮窗以等宽数字仅测量当前时间格式：不足一小时MM:SS，小时出现才扩成HH:MM:SS，小时位增长才再次扩宽；同格式逐秒稳定，自然测量更长读数后统一交给原安全区域几何，保留时间锚点，不裁剪、自动缩字或停止刷新。通知使用已有服务采样显示统一读数；桌面仍由原生Chronometer计秒，只在1小时/10小时格式区间变化时更新补零格式，未新增逐秒组件轮询。厂商可限速通知刷新，原生桌面外观需真机观察。
