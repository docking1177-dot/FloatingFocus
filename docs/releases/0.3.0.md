# Floating Focus 0.3.0（公开测试版）

2026-10-29；versionCode 4，最低 Android 10，targetSdk 36。沿用工作区固定 Debug 签名，包含开发者模式及仅 Debug 的预设样式比较，不是商店发行签名包。

## 更新

- 首次使用教程与末页悬浮权限引导，设置可重新查看。
- 首页三卡分组、快捷 App 图标网格、预设稳定位置、分秒滚轮、独立变色与变尺寸、双节点提醒策略。
- 预设桌面快捷方式读取最新配置；补充 Redmi 厂商快捷方式权限指引、未确认反馈，已有会话不被替换。
- 常用时长页配置启动默认模式与倒计时时长；返回、重建及活跃会话不被默认值覆盖，不自动开始。
- 时长记录增加今日/本周/本月图表、历史 App 筛选；CSV 仍导出全部原始记录。
- C4 独立主题、完整键盘、双向折叠及常态图案，修复 LCD/键盘布局。最后44.439秒进入，4.92秒后可输入7355608；仅口令正常结束，系统清理仍有效。

## 安装

下载 FloatingFocus-0.3.0-debug.apk。与此前本机固定签名测试版可覆盖安装，保留配置和记录；GitHub Actions 临时签名包不保证兼容。更新前结束计时，可先导出CSV。签名不兼容时不要为强行安装而直接卸载丢失数据。

附件提供 SHA256SUMS.txt、BUILD_INFO.json 和本说明；源码由GitHub提供标签压缩包。

## 验证与限制

- 发布源码执行本地 Debug/Release 完整构建、单测与Lint；发布门禁使用同一源码与APK的smoke、edges、inline模拟器报告，具体数量见BUILD_INFO。
- 本轮开发版此前通过启动默认配置、实际桌面图标点击及C4拖动/折叠/输入回归；公开包不含私有录音，不能以本机有录音版本的播放日志代表公开包听感。
- C4录音授权未确认，仅本机Debug使用，不在本次APK或仓库中；公开包无下包、滴声、爆炸及解除语音，计时与键盘仍可工作。LED依据用户LRC标注，不宣称原版实测还原。
- REDMI K80最新完整真机验收未完成。用户已确认允许厂商「桌面快捷方式」权限后能生成图标；其他启动器、不支持固定入口及等待确认时编辑/删除的真机竞态未完整验收。
- 记录为FF会话，全部包含手动计时；异常中断只能保证最后检查点，停机时间不补算。自动App监测保持Deferred，无新监测权限或保活。
