# Floating Focus 0.2.0（公开测试版）

本次是手动悬浮计时功能里程碑，提供固定本地签名的 Debug APK，包含提醒实验室。最低 Android 10，targetSdk 36。

## 本次更新

- 倒计时归零后继续超时正计时，浮窗内自定义加时；另有独立正计时。
- 本地会话记录、异常中断检查点恢复和 CSV 导出。
- 常用 App 快捷启动；预设保存目标 App、时长与完整外观，双列网格一键启动并支持管理。
- 正式设置与实时预览；三种浮窗形状、颜色／尺寸变化方式、强度、大小和透明度。
- 修复贴边展开／收起漂移、文字矩形背景及点击色块、初始尺寸与到期振动问题。
- 拉开橙红阶段色差；提醒由变淡改为提亮，保持设置的透明度。
- 首页压缩间距、删除冗余大时间卡片与无实际意义文案。

## 安装与更新

下载 **FloatingFocus-0.2.0-debug.apk**。versionCode 从 2 增至 3，签名与此前本机交付的测试包相同，可覆盖同签名版本并保留数据。更新前结束正在进行的计时；需要保留的时长记录可先导出 CSV。其他机器或 GitHub Actions 临时签名包可能无法覆盖，请勿为解决签名差异直接卸载而丢失数据。

随附 SHA256SUMS.txt 和 BUILD_INFO.json。GitHub 页尾提供标签对应的源码压缩包。不要把 CI 临时签名 artifact 当作本次发布 APK。

## 验证与已知边界

- 本地 Debug 75 项、Release 69 项 JVM 测试、两种构建及 Lint 通过；Debug 仅有既有 Gradle 更新警告。
- Android 16 模拟器覆盖更新保留配置／记录，预设启动、悬浮显示、停止和历史记录检查通过；此前完成核心交互、加时、导出与动画回归。
- 最新完整 REDMI K80 真机回归尚未完成。此前该手机确认振动成功，不代表所有系统设置与后台场景都已通过。
- 时长记录是 FF 会话时长，不是 App 前台使用统计；强杀恢复按最后检查点标记约计。深度休眠可能延迟到期提醒。
- 指定 App 自动计时仍为 Deferred，不申请使用情况访问／无障碍权限，也不自动监听切换 App。
